# 步骤 01 · 产出用 prompt / 改写思路

> 记录本次解说词产出时给 LLM 的核心指令与改写思路（来自 PIPELINE-DESIGN §3 版本归档要求）。
> 目的：可复核、可重生、可回退。

## 角色设定
你是解说短剧的编剧。把提供的英文剧本本集改写成**口播体中文解说词**。

## 核心要求（对应 TASK-SPEC §4 / §7-01）
1. 口播体：自然连贯、可直接念出，不是书面梗概。
2. 讲清人物关系、事件因果、情绪变化。
3. 保留关键对白（用「原文引号」保留并标注角色与情绪）；保留关键情绪点。
4. 只做本集，不串剧情；按场景/节拍切分。
5. 每个节拍留「画面要素提示」位（人物/动作/场景/证据），供步骤 02 分镜。

## 改编边界（默认保守，待确认）
- 只做必要口语化与顺序理顺；**不改情节、不删关键对白**。
- 任何压缩/删改/重组须在 narration.md §4 列出并标注「待确认」。

## 输出结构
严格按 `narration.md` 的 0–5 节结构输出（本集信息 / 人物速览 / 旁白正文节拍 / 对白清单 / 改编说明 / 预估备注）。
